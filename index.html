核心构成：平台与语言

支叶平台

可学习的交互内核。提供记忆、执行、多模态感知等基础能力，并能在运行时吸收新知识。

Y语言

平台的动态接口。不是需要编译的静态语言，而是可被实时"教学"以扩展平台理解的交互协议。

支叶融合 — 连接 AI 与万物的底座

一面接入万物（硬件、传感器、设备），一面直连 AI。AI 用 Y 语言直接调用支叶全部能力，也能照 C++ 扩展模板自己开发新 DLL，能力边界随 AI 无限生长。

支叶自带智能体 — 平台自己的 AI

不依赖任何外部工具，支叶自身就是智能体：自己思考、自己写 Y 代码、自己执行、拿结果再修正，直到任务完成。

自带 agent 库扩展

agent 带有 open / chat / ctx / feedback 接口。通道句柄相互隔离，多个智能体可并行处理不同任务；OpenAI / Claude / Ollama 三种协议，云端模型与本地模型自由切换。

会写，也会执行

模型输出 ```y 代码块，支叶用 runstr 直接执行；agent.feedback 把执行结果回灌，下一轮接着改，形成闭环。

多智能体协作

mqopen / mqsend / mqrecv / mqclose 消息队列：主智能体派活、子智能体回传。阻塞等待零轮询，队列满时新状态覆盖旧状态。

能力即工具

UI 画布、摄像头、串口、语音、PDF 读写与翻译、文本与 JSON、国密加密、视觉识别——全部以 Y 语言函数暴露，智能体直接调用。

开发调试支叶本身可用 Claude Code 或 WorkBuddy：打开 nlurh/ 文件夹并提到"支叶"即可，内置 Skill 文件开箱即用。

交互视窗（Tauri）—— 图形化运行支叶

专为支叶人机交互开发的 UI 工具。界面上提供的 agent 按钮，可方便地从支叶常规交互切换到智能体交互模式。

A learnable human-computer interaction kernel, and its teachable interface — the Y Language

No recompilation needed. Empower machines through conversation.

GitHub Repository Try It Now

From "Programming" to "Teaching": A New Interaction Paradigm

Traditional automation requires re-coding and recompiling for every new feature. On the Zhiye Platform, you "teach" the system new instructions and logic through the Y Language. The platform understands and remembers them at runtime, enabling continuous growth of interactive capabilities.

Core Components: Platform & Language

Zhiye Platform

The learnable interaction kernel. Provides foundational capabilities like memory, execution, multimodal perception, and can absorb new knowledge during runtime.

Y Language

The platform's dynamic interface. Not a static language that needs compilation, but an interactive protocol that can be "taught" in real-time to extend the platform's understanding.

Zhiye Convergence — The Bridge Between AI & Everything

One side connects to everything (hardware, sensors, devices), the other face connects straight to AI. AI drives every Zhiye capability through Y Language — and can build new DLLs from the C++ template, so the boundary grows with AI.

The Built-in Zhiye Agent — AI That Lives in the Platform

No external tooling required — Zhiye is the agent: it thinks, writes Y code, executes it, reads the result, and corrects itself until the job is done.

Bundled agent library extension

The agent exposes open / chat / ctx / feedback interfaces. Channel handles are isolated, so many agents run different tasks in parallel; OpenAI / Claude / Ollama protocols — cloud or local models, switch at will.

Writes, and executes

The model answers with a ```y code block; Zhiye runs it directly via runstr. agent.feedback feeds the result back, so the next round improves on it — a closed loop.

Multi-agent collaboration

mqopen / mqsend / mqrecv / mqclose message queues: the main agent dispatches, sub-agents report back. Condition-variable blocking, zero polling; when full, the newest state overwrites the oldest.

Capabilities as tools

UI canvas, camera, UART, speech, PDF read/write & translation, text and JSON, Chinese national cryptography, vision — all exposed as Y functions the agent calls directly.

To develop and debug Zhiye itself, use Claude Code or WorkBuddy: open the nlurh/ folder and mention "Zhiye" — the bundled Skill files work out of the box.

Chat Window (Tauri) — Run Zhiye Graphically

A UI built specifically for Zhiye's human-computer interaction. Its agent button switches you from regular interaction to agent mode at a click.
