💡 The Teachable Interface Paradigm

Beyond prompts, beyond rigid commands. Y Language operates on the Zhiye Platform as a malleable layer between your words and machine actions. You “teach” it the correct mapping through examples and rules, enabling it to parse natural language accurately and execute tasks reliably.

不同于提示词，也不同于僵硬指令。 Y语言在支叶平台上，作为您的语言与机器行动之间的可塑层运行。您通过示例和规则“教导”它正确的映射关系，使其能够准确解析自然语言并可靠地执行任务。

✨ Core Capabilities

我们将强大的能力封装为简单的Y语言接口，让您可以专注于“教导”系统理解您的意图。

Local LLM Integration

Natively call models like DeepSeek R1 directly on edge devices for offline, private AI reasoning.

Multimodal Perception

Integrated YOLOv5 object detection and face recognition, giving programs "eyes" to see the world.

Hardware Interaction

Direct control of the physical world via UART, GPIO, and other interfaces. Deployed on RV1106.

Natural Language Interface

Parse complex natural language instructions into executable task flows for intuitive human-AI collaboration.
